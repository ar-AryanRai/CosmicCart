# 🪐 Cosmic Cart – Interplanetary E-Commerce Website

**Cosmic Cart** is a unique and interactive e-commerce website where users can "buy" different **planets** from the cosmos. Designed to mimic real-world shopping platforms, the website combines creativity with core frontend development practices using **HTML5**, **CSS3**, **Tailwind CSS**, and **JavaScript**.

🌐 **Live Site**: [ar-aryanrai.github.io/CosmicCart](https://ar-aryanrai.github.io/CosmicCart/)

---

## 📌 Project Overview

This project imagines a futuristic store where celestial bodies are up for sale. It features smooth navigation, engaging design, animated product display via **Swiper.js**, and user-friendly functionality for browsing, selecting, and purchasing planets. It has a fully functioning cart and we can can even apply/validate coupons for the purchase.

Whether you're in the market for Mars or Saturn, Cosmic Cart offers a fun spin on classic e-commerce experiences.

---

## 🚀 Tech Stack

- **HTML5** – Structure and semantic markup  
- **CSS3** – Base styling and layout  
- **Tailwind CSS** – Rapid UI development with utility classes  
- **JavaScript** – Interactivity, dynamic rendering, and DOM manipulation  
- **Swiper.js** – Carousel for product browsing  
- **Local Storage** – To persist cart data across sessions  

---

## ✨ Features

- 🪐 **Carousel-style product viewer** for planets using Swiper.js  
- 🛒 **Buy Now** and **Add to Cart** functionality  
- 🧾 **Coupon code** integration to apply discounts  
- 💾 **Local storage** used for cart and order management  
- 📱 **Responsive layout** with Tailwind CSS for mobile & desktop  
- 🎨 **Custom styling** via `home.css` for circular planet displays and unique layout  
- 🔔 Popup messages for cart updates and purchase confirmations
